The Offer

A Real Manual Test — That Also Leaves You Able to Detect Attacks

A scoped manual web & API penetration test, delivered in 2–3 weeks by an operator who builds defensive security tooling for a living. Fixed scope, fixed fee, no surprises.

🔎

Manual testing of your web app + API

Authentication, authorization / access control (IDOR, BOLA), injection, business-logic flaws, session handling, and common misconfigurations — the classes that actually get breached, not just an automated scan.

📋

A report you can actually use

Each finding with severity, reproduction steps, business impact, and a concrete fix — written to hand straight to a developer, and to a customer's security reviewer.

For the findings, I write the Sigma / Suricata / Falco detection rules so that if someone does try that attack later, you see it. Most pentests hand you a list of holes; this one also leaves you able to detect the attempts.

One free re-test within 30 days

After you fix the findings, I re-test to confirm they're closed — so you can show a clean result, not just a list of problems.
